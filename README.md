# Delta
A simple lap data analyzer with mock data. 
The basic premise is that you have your sector's top speed, thottle input and brake input. 
Input between 0.0-1.0 is how much pressue is applied on either
If the speed or input are the same, then the output will be NaN
If one is greater than the other then it will be highlighted in green. With more than 2 laps, the fastest sector will be purple as standard

Of course this means a slow sector time and input will be highlighted in red

There will be updates in the future 
Hope you enjoy!
